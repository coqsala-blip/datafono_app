# Copilot instructions for this workspace

- This repository is an Expo app. Before writing or changing code, read the exact Expo versioned docs for the current app version in `AGENTS.md`.
- Treat the user as the final approver for all file edits and project changes.
- When the user asks to implement something, first explain the planned change briefly, then wait for explicit approval before applying code edits.
- Do not edit files, run destructive commands, install dependencies, or change project configuration without the user's confirmation.
- Keep edits minimal, targeted, and easy to review.
- After making approved changes, run the smallest relevant verification command available (for example `npx expo lint` if applicable) and report the result.
- If the user wants automatic assistance, only proceed in a consented workflow: propose, confirm, then apply.
